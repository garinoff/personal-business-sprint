# Личный бизнес-спринт

Статическая версия дашборда для GitHub Pages, включая вкладку «Руководство».

Публикация: Settings → Pages → Deploy from a branch → main → / (root).

Журнал сохраняется в localStorage текущего браузера. Данные с другого домена автоматически не переносятся. Серверный API /api/pilot не входит в этот пакет; ИИ-функции требуют отдельного защищённого backend.
